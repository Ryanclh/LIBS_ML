Phase 1: Data Preprocessing & Preparation
Goal: Clean the 12,981 raw features to remove noise and physical interference (Matrix Effects).
Data Loading & Splitting:
Load the 324 samples $\times$ 12,981 features.
Stratified Split: Split data into Training (70%) and Testing (30%) sets. Use stratified sampling to ensure both sets have an equal distribution of High, Medium, and Low nutrient classes.
Baseline Correction:
Apply Asymmetric Least Squares (ALS) smoothing to remove the "continuum background" (the shifting slope of the spectrum caused by Bremsstrahlung radiation).
Noise Reduction:
Apply a Savitzky-Golay Filter (e.g., window size=11, polynomial order=3) to smooth out high-frequency sensor noise without distorting the peak shapes.
Normalization:
Apply L2-Normalization (Euclidean norm) to each spectrum. This scales the data to a range of 0–1, compensating for shot-to-shot variations in laser energy.
Phase 2: Systematic Feature Selection (Research Gap Focus)
Goal: Reduce 12,981 features to <100 to enable "Lightweight" and "High Accuracy."
Method 1: Filter-Based (Statistical):
Apply ANOVA F-value scoring.
Select the top 100 wavelengths that show the highest statistical variance between nutrient classes.
Method 2: Embedded (Tree-Based):
Train a standard Random Forest on the full spectrum.
Extract the Gini Importance scores.
Select the top 100 features that the trees found most useful for splitting classes.
Method 3: Domain-Knowledge (Hybrid):
Use the NIST Atomic Spectra Database to identify theoretical peaks for N, P, K, Pb, Cd, Cr.
Create a "Mask" that only selects indices within $\pm$0.5nm of these theoretical peaks.
Selection & Consensus:
Compare the accuracy of these three subsets.
Decision: Proceed to Phase 3 with the best-performing subset (e.g., "The Random Forest subset of 65 features").

PHASE 1: PREPROCESSING (Scientifically Validated)
1. Baseline Correction: Asymmetric Least Squares (AsLS)
✅ Selected & Justified
Evidence:
LIBS soil carbon study: AsLS + spectral ranges achieved Pearson's r = 0.93, RMSE = 0.21, outperforming single-line regression (r = 0.91, RMSE = 0.26) - 19% RMSE improvement​
Lithium detection 2024: AsLS + Gaussian regression achieved R² = 0.93​
Mars LIBS study: airPLS (alternative method) "had little effect" compared to AsLS​
Why this method: AsLS is physics-based (removes Bremsstrahlung continuum) and has automatic parameter selection.​

2. Noise Reduction: Savitzky-Golay Filter
⚠️ Selected with CAUTION - Consider Testing Alternative
Evidence:
Standard LIBS practice: SG "reduces high frequency noise while preserving peak height"​
CRITICAL 2022 WARNING: Schmid (197 citations) states SG filters "should be replaced" - poor noise suppression above cutoff frequency, Modified Sinc (MS) filters provide better stopband rejection​
Recommendation:
IMPLEMENT BOTH and compare:
Primary: SG (window=11, poly=3) - for compatibility with LIBS standard practice
Experimental: Modified Sinc filter or Gaussian smoothing - may improve accuracy by >2%
Why: If MS filter improves accuracy, document this as a methodological contribution. If SG performs equally well, justify using it for lower computational cost on MCU.

3. Normalization: L2-Norm
✅ Strongly Justified
Evidence:
2025 validation study: L2-norm showed zero bias (0.000), RMSE = 0.002 vs SNV (RMSE = 0.220 - WORST)​
LIBS thesis: "L2 normalization corrects for energy fluctuations of laser pulses between shots"​
EMSLIBS contest: Total area normalization (L1-equivalent) successfully "reduced matrix effect" in LIBS soil classification​
Why L2 > SNV: SNV produced worst RMSE due to zero-centering creating interpretation difficulties.​

PHASE 2: FEATURE SELECTION (Research Gap Focus)
4. Method 1: ANOVA F-Test (Filter-Based)
✅ Justified as First-Pass Filter
Evidence:
Intrusion detection: ANOVA F-test improved accuracy by >10% for multiclass (NSL-KDD: 82.29% → 84.38%)​
EEG stress classification: ANOVA improved accuracy 87.8% → 91% with 33 features selected​
Computational efficiency: ANOVA is faster than wrapper methods, suitable for screening 12,981 features​
Limitation acknowledged: Univariate methods miss multivariate spectral interactions that Random Forest Gini identifies.​
Strategy: Use ANOVA to reduce 12,981 → ~500 features, THEN apply RF Gini for final selection to ~100 features.

5. Method 2: Recursive Feature Elimination (RFE)
✅ Justified for Multivariate Selection
Evidence:
Sonar dataset: RFE achieved 95.9% AUC with optimal 19 features (from 60)​
Logistic regression study: RFE (top 10 features) achieved 97.37% accuracy​
Hybrid ANOVA-RFE: Selected 5 features achieving 99.96% accuracy with Random Forest​
Advantages: Considers feature interactions (unlike ANOVA), model-agnostic, auto-optimizes feature count via cross-validation.​
Limitation: Computationally intensive - mitigate by pre-filtering with ANOVA.​

6. Method 3: Random Forest Gini Importance (BEST for Spectral Data)
✅ STRONGEST JUSTIFICATION - Primary Method
CRITICAL EVIDENCE for Spectroscopy (409 citations):​
RF Gini importance outperformed univariate statistical tests (ANOVA, t-test) on spectral data
"Spectral regions deemed unimportant by univariate measures (ANOVA) may be attributed HIGH importance by multivariate Gini, indicating features of higher order interaction"
No selection bias on continuous spectral data (unlike categorical data)
RF Gini + PLSR classification performed better than direct RF classification
Soil-Specific Evidence:
Soil texture study: RF outperformed KNN, MLP, SVM, XGB for soil particle size fraction prediction​
Agricultural soil: "Feature importance scores determined using RF algorithm"​
Why PRIMARY for your 12,981 LIBS features: Literature proves superiority over univariate tests for spectroscopy, captures synergistic peak interactions.​
